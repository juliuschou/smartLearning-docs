# 智學互動平台 — 系統雛形（純 JS + HTML）

依 `../20_系統分析`（M01–M11 使用者需求與驗收規格）製作的互動式系統雛形。**無框架、無 build step、無相依套件**，直接以瀏覽器開啟 `index.html` 即可使用。介面用語以 `../20_系統分析/GLOSSARY.md` 為唯一基準。

## 檔案

| 檔案 | 內容 |
|---|---|
| `index.html` | 登入頁 + 管理端 shell（M01–M07、M09、M10） |
| `learner.html` | 學員端（M08）：加入 → 暱稱 → 等候 → 作答 → 收看已公布結果 |
| `projection.html` | 投影畫面（M07-09/M09-04）：Game PIN／題目／已公布結果；按 `L` 鍵模擬失聯 → 安全待機畫面 |
| `assets/app.js` | 管理端邏輯與頁面 |
| `assets/learner.js` | 學員端邏輯 |
| `assets/seed.js` | 示意資料（帳號、權限目錄、題庫、活動） |
| `assets/style.css` | 樣式 |

## 試用流程

1. 開啟 `index.html`。示範帳號（密碼在 `assets/seed.js`）：
   - `admin@example.com` — 系統管理者（看 M02/M03/M04/M10）
   - `teacher@example.com` — 老師（看 M05/M06/M07/M09）
   - `off@example.com`／`Off12345` — 停用帳號，登入被拒（回覆為一般化訊息，防帳號枚舉）
2. 老師：教學活動管理 → 「公益團體急救共學」→ 開啟控制台 → 選擇第一題 → 開放作答 → 停止作答 → 公布統計／正確答案／排行榜
3. 另開 `learner.html?pin=007432` 與 `projection.html?pin=007432` 觀察學員端與投影；學員端有「（示意）老師公布…」按鈕可觸發公布的顯示

## 已反映的主要規則

- 登入失敗一律一般化訊息；不限失敗次數；忘記密碼 30 分鐘一次性連結、60 秒寄送限制
- 前端選單依有效權限過濾（admin 與 teacher 看到不同選單）；標注「僅為 UX，非安全邊界」
- M04 批次儲存完整權限集合（全有全無）；P1 權限停用不可指派；權限變更重新登入後套用
- M05 軟刪除／復原、複製（副本命名流水號）、題型規則提示
- M06 模式相容性（`grouping_mode`／`leaderboard_mode` 全名書寫）、題目快照（`SESSION_QUESTION`）、加入資訊輪替整組失效
- M07 活動狀態／題目狀態／三項公布狀態分別呈現；公布不可撤回；不得跳題返回；人數三指標（在線／已加入／已作答）分開顯示；TEAM 分組確認即鎖定、首道計分題開放後禁解鎖
- M08 暱稱選填／系統分配顯示名稱、等候狀態、開放期間可更新提交、學員端公布統計僅答案分布（經測試不含正確率）
- M09 競賽排名（1、1、3）vs 密集排名（1、1、2）、資格人數 0 顯示「不適用」、`leaderboard_mode=NONE` 仍提供教師彙總
- M10 批次更新全有全無、「未知」連線狀態
- 待決議事項以虛線框「待決議」標示（控制端租約、參與者憑證格式、活動允許加入期間等）

## 限制（雛形範圍）

- 資料僅存在於記憶體（重新整理即還原示意狀態）；無後端、無即時通道
- 題目逐題編輯表單、報表匯出（P1）、組織競賽（P1）以提示說明呈現，未完整實作
