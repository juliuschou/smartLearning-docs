# M08 學員互動管理—使用者需求與驗收規格

> **來源：**《即時互動教學系統 — 系統功能規劃書 V1.2》M08（學員互動管理）、相關角色權限矩陣、M06 活動生命週期、M07 老師即時控制、M09 統計與結果、M11 分組與競賽規則，以及 BR-008～BR-010、BR-016～BR-017、BR-020、BR-024、BR-028、BR-030。
> **模組優先級：** P0
> **規格狀態：** 依 V1.2 與已確認跨模組規則整理；來源未定義的參與者憑證、提交修改政策及文字欄位限制列於待確認事項，不由實作自行推定。

## 1. 需求概覽與假設

- **功能目標：** 讓學員不需建立正式帳號即可加入教學活動，在老師開放的題目中作答、投票或提交文字回饋，斷線後恢復目前活動狀態，並依活動模式及老師公布狀態接收適用結果。
- **範圍：** 涵蓋 M08-01～M08-12：加入活動、設定暱稱、等候、單選／多選作答、意見投票、文字回饋、接收結果、重新連線、檢視所屬隊伍、接收團隊結果、不分組個人互動及接收個人結果。
- **參與者與身分：** 學員是單場活動的臨時參與者（`Participant`），不納入 M02 正式帳號角色管理。系統須能在活動範圍內唯一區分參與者（BR-009）；匿名顯示不等於匿名建立身分，亦不得妨礙斷線重連及防止重複計分（BR-020）。
- **加入前置條件：** 學員使用該活動的 Game PIN、活動連結或 QR Code 加入；加入憑證、活動狀態及可加入條件由 M06／平台契約提供。活動已結束或憑證無效時不得建立新參與者。
- **題目與活動狀態：** 活動啟動不等於題目開放。只有目前題目處於老師開放作答狀態時，學員才可提交該題答案（BR-008）；停止作答與提交競態依伺服器原子處理順序裁決。
- **模式：** `INDIVIDUAL` 不建立隊伍，學員直接參與問答、投票及文字互動（BR-024、BR-028）。`TEAM` 才顯示所屬隊伍；啟用團隊排行且老師公布後，才可接收團隊排名。個人結果依 `INDIVIDUAL` 模式、個人排行設定及老師公布狀態顯示。
- **範圍界線：** M08 負責參與者加入／恢復、互動提交及學員端結果呈現；活動與加入憑證生命週期由 M06 管理，題目開放／關閉及公布控制由 M07 管理，統計與分數計算由 M09 負責，隊伍、資格快照及團隊計分由 M11 負責。M08 不執行老師控制、分組管理或統計／計分公式。

## 2. 功能範圍

> 暱稱選填／系統分配及重名辨識方式沿用 M06；M08 僅定義學員端互動與結果權限，不另行覆寫該政策。

| 功能 ID | 功能名稱 | 功能說明 | 範圍界線 |
|---|---|---|---|
| M08-01 | 加入活動 | 透過 PIN、活動連結或 QR Code 加入指定活動。 | 三種入口指向同一活動加入流程；活動狀態及憑證有效性由 M06／平台契約驗證。 |
| M08-02 | 設定暱稱 | 學員輸入暱稱或使用系統分配的顯示名稱。 | 暱稱不取代參與者唯一識別；欄位限制依 M06／平台契約。 |
| M08-03 | 等候活動 | 加入後等待老師啟動活動或開放題目。 | 未開放題目時不得提交答案；活動啟動不等同題目開放。 |
| M08-04 | 選擇題作答 | 提交單選或多選答案。 | 僅接受目前開放題目且符合題型的提交；開放期間允許更新，採最後一次成功提交。 |
| M08-05 | 意見投票 | 提交沒有標準答案的投票選項。 | 投票無標準答案；預設不計分（BR-017）。 |
| M08-06 | 文字回饋 | 提交文字答案或心得。 | 預設不計分；字數、內容治理及可見範圍依待確認事項及平台契約。 |
| M08-07 | 接收結果 | 接收老師已公布且該學員有權檢視的統計、答案或結果。 | 統計、正確答案及排行榜是獨立公布項目；M09 教師／報表統計不得直接作為學員端公布資料。 |
| M08-08 | 重新連線 | 短暫斷線後恢復目前活動狀態及參與者身分。 | 不得建立重複參與者、重複答案或重複計分；重連憑證及有效期限依平台契約。 |
| M08-09 | 檢視所屬隊伍 | 在分組模式檢視本人所屬隊伍名稱及核准的競賽狀態。 | 僅 `TEAM` 模式適用；不得檢視未授權的其他隊伍成員資料。 |
| M08-10 | 接收團隊結果 | 在團隊排行啟用且老師公布後接收團隊排名。 | 僅 `TEAM` + `leaderboard_mode=TEAM` 適用；資料由 M09／M11 提供。 |
| M08-11 | 不分組個人互動 | 不經分組，直接答題、投票及提交意見。 | `INDIVIDUAL` 不建立隊伍、隊員關聯或團隊結算資料。 |
| M08-12 | 接收個人結果 | 在個人排行啟用且老師公布後接收本人個人分數或排名。 | 僅 `INDIVIDUAL` + `leaderboard_mode=INDIVIDUAL` 適用；資料由 M09 提供。 |

## 3. 使用者故事

> **身為**持有有效活動加入資訊的學員，
> **我希望**不需建立正式帳號即可加入活動、參與目前開放的互動，並在斷線後恢復狀態及查看已公布且適用於我的結果，
> **以便於**順利參與現場教學並掌握自己的學習回饋。

## 4. 參與者、互動與結果狀態規則

### 4.1 狀態與責任區分

1. **活動狀態：** 活動是否允許加入及互動由 M06 提供；已結束活動不得建立新參與者或新增作答。既有資料保存及唯讀結果範圍依 M06／平台資料保存政策。
2. **題目狀態：** M07 提供目前題目及作答是否開放。題目未開放或已停止時不得接受新的提交；學員端不得自行改變題目狀態。
3. **參與者狀態：** 已加入、在線及具備特定題目作答資格是不同概念。M08 需使用穩定的活動內參與者識別；在線判定由最近 60 秒內有效心跳的契約定義，不得用在線狀態替代已加入人數或 M11 的題目資格快照。
4. **提交狀態：** 伺服器成功接受的提交才可供 M09／M11 使用。停止作答與提交競態依伺服器原子處理順序裁決：提交先被接受則有效；停止轉換先完成則提交無效。網路重送不得重複建立參與者或累積分數。
5. **公布狀態：** 老師公布統計、公布正確答案及公布排行榜為不同狀態，由 M07 控制。學員只能讀取已公布且與活動模式及本人權限相符的資料；不得由 M08 推導或提早公開未公布結果。
6. **分組狀態：** `TEAM` 的隊伍及成員歸屬由 M11 提供；M08 僅呈現本人所屬隊伍及被允許的結果，不提供建立、調整或解鎖分組功能。`INDIVIDUAL` 不建立或呈現團隊資料。

### 4.2 互動提交規則

- 只有活動允許互動、目前題目由老師開放，且參與者符合該互動的參與條件時，才接受提交。計分題須具備 M11 定義的題目資格；遲到者可參與加入時仍開放的非計分投票／文字互動，但不得因此取得已開放計分題資格。題型、選項及必要欄位須與活動題目快照相符。
- 單選、多選、投票及文字回饋是不同題型；不接受與題型不相符的答案格式。投票與自由文字預設不計分（BR-017），M08 不自行判定正確率或計算分數。
- 題目停止後拒絕新的有效提交；已被伺服器接受的資料保留供後續統計／計分。選擇題、投票及文字回饋在作答開放期間允許更新，最後一筆成功提交為有效內容；網路重送同一請求仍須冪等，不視為有效更新或重複計分。
- M08 不得把離線暫存或尚未確認送達的內容呈現為已提交。重試若使用相同提交識別資訊，須避免重複寫入或重複計分；具體冪等契約依平台／M09 定義。

### 4.3 加入、遲到與重連

- PIN、活動連結及 QR Code 均導向同一活動加入流程；加入時由後端驗證憑證與活動狀態，拒絕無效、撤銷、過期或已結束活動的加入要求。
- 加入後若活動已啟動但沒有開放題目，學員進入等候狀態；不得因已加入或已在線而取得作答資格。
- 對計分題，遲到者只可自尚未開放且符合資格的後續題目開始參與計分，不得追溯加入已開放題目的資格快照或已結算分數（BR-016、M11）。依本次決策，遲到者仍可參與加入時尚開放的非計分投票／文字互動；此類互動不改寫計分資格快照。
- 重新連線應恢復同一活動內參與者身分及可恢復的目前狀態，不得另建第二個參與者。不能驗證重連身分時不得將其視為原參與者或回傳他人資料；有效憑證遺失、到期後的恢復方式待平台契約確認。

### 4.4 結果可見條件

| 活動模式與設定 | 學員端可見內容 | 不可見內容／限制 |
|---|---|---|
| `INDIVIDUAL` + `NONE` | 老師已公布且核准提供的答案分布／結果。 | 不顯示隊伍、團隊分數或排行榜；不因 M09 計算個人分數而自動顯示個人排名。 |
| `INDIVIDUAL` + `INDIVIDUAL` | 老師公布後，本人適用的個人分數或排名；另可接收核准公布的統計／正解。 | 未公布的個人排名不得取得；不得顯示團隊資料。 |
| `TEAM` + `NONE` | 本人所屬隊伍名稱及老師已公布的核准結果。 | 不顯示團隊排行榜；不得檢視未授權的其他隊伍成員個資。 |
| `TEAM` + `TEAM` | 本人所屬隊伍名稱；老師公布後的團隊排行榜，以及其他已核准公布內容。 | 未公布的團隊排名及原始個人作答不得取得。 |

學員端「公布統計」僅顯示答案分布；不得包含未作答人數、正確率或文字回饋（依 M07 公布範圍）。公布統計不代表公布正確答案或排行榜。組織間競賽屬 P1，不納入本版 M08 可執行範圍。

## 5. 驗收條件

```gherkin
Feature: M08 學員互動管理

  Background:
    Given 學員以單場活動臨時參與者身分操作，無須正式帳號
    And 後端以有效活動加入憑證及活動內 Participant 識別驗證學員
    And 活動狀態、題目狀態、作答資格及公布狀態以 M06、M07、M09、M11 契約為準

  Scenario: 以 PIN、活動連結或 QR Code 加入有效活動
    Given 活動尚未結束且允許新學員加入
    And 學員提供該活動有效的 PIN、連結或 QR Code
    When 學員提出加入要求
    Then 系統驗證加入資訊並建立唯一的活動內 Participant
    And 三種加入方式均導向同一活動加入流程
    And 系統不要求建立正式帳號

  Scenario: 無效或失效加入資訊不得建立參與者
    Given 學員提供不存在、錯誤、已撤銷或已失效的活動加入資訊
    When 學員提出加入要求
    Then 系統拒絕加入且不建立 Participant 或 Response
    And 回覆不洩露其他活動或參與者資料

  Scenario: 已結束活動拒絕新加入
    Given 指定活動已結束
    When 學員使用仍留存的 PIN、連結或 QR Code 加入
    Then 系統拒絕建立新 Participant
    And 活動既有作答及結果不因加入要求而改變

  Scenario: 設定暱稱或取得系統分配名稱
    Given 學員的加入要求已通過驗證
    When 學員提供暱稱，或未提供暱稱
    Then 系統依 M06 規則保存暱稱，或分配活動內唯一顯示名稱
    And 重複暱稱依 M06 規則附加辨識序號
    And 顯示名稱不得取代 Participant 的唯一識別

  Scenario: 加入後等待老師開放題目
    Given 學員已加入活動
    And 活動尚未啟動，或目前沒有開放作答的題目
    When 學員檢視目前活動狀態
    Then 系統呈現等候狀態及可由 M07 公布的活動資訊
    And 學員不得提交尚未開放題目的答案

  Scenario: 開放題目後提交符合題型的單選或多選答案
    Given 學員已加入且符合目前題目的作答條件
    And 老師已透過 M07 開放單選或多選題
    When 學員提交符合題型與題目快照的答案
    Then 系統接受並關聯該活動、題目及 Participant
    And 已接受答案可供 M09／M11 後續統計或計分
    And M08 不自行計算統計或分數

  Scenario: 多選答案為空或包含重複選項時整筆拒絕
    Given 多選題已開放且 Participant 符合目前互動條件
    When 學員提交空選項集合或含重複選項的集合
    Then 系統拒絕整筆提交
    And 不保存部分答案或更新既有有效答案

  Scenario: 遲到學員參與仍開放的非計分互動
    Given 學員在投票或文字題開放後才加入活動
    And 該題仍開放且屬非計分互動
    When 學員提交符合題型的投票或文字回饋
    Then 系統接受並關聯該活動、題目及 Participant
    And 該提交不改寫任何計分題資格快照或已結算分數
    And 該互動依規則不計分

  Scenario: 提交投票或文字回饋
    Given 學員已加入且符合目前題目的互動條件
    And 老師已開放投票或文字題
    When 學員提交符合題型的投票選項或文字內容
    Then 系統接受並關聯該活動、題目及 Participant
    And 投票及自由文字預設不計分
    And 系統不自行推定投票或文字題的正確答案

  Scenario: 題目尚未開放或已停止時拒絕提交
    Given 題目尚未開放，或 M07 已停止該題作答
    When 學員提交該題答案、投票或文字回饋
    Then 系統拒絕該提交且不納入統計或計分
    And 題目、活動及已接受的既有答案保持不變

  Scenario: 提交格式與目前題型不相符
    Given 目前題目已開放
    When 學員提交與題型不相容的資料或不存在的選項
    Then 系統拒絕該提交並回覆可修正的欄位或題型錯誤
    And 不保存部分答案且不影響已接受的提交

  Scenario: 停止作答與提交並行時依伺服器順序裁決
    Given 學員提交答案與老師停止同一題作答並行抵達
    When 伺服器原子處理提交及停止狀態轉換
    Then 若提交先被伺服器成功接受，該答案有效並保留
    And 若停止轉換先完成，該提交遭拒且不納入統計或計分

  Scenario: 開放期間答案更新以最後成功提交為有效
    Given 學員已成功提交目前開放題目的答案
    When 學員再次提交不同且有效的選擇題或投票答案
    Then 系統以最後一筆成功提交作為該 Participant 該題的有效答案
    And 更新僅計入一次有效作答，不重複累積分數

  Scenario: 開放期間答案更新以最後成功提交為有效
    Given 學員已成功提交目前開放題目的答案
    When 學員再次提交不同且有效的選擇題或投票答案
    Then 系統以最後一筆成功提交作為該 Participant 該題的有效答案
    And 更新僅計入一次有效作答，不重複累積分數

  Scenario: 網路重送不得造成重複作答或重複計分
    Given 學員已提交答案但因網路狀況未收到確認
    When 學員以相同提交識別重試，或重連後重送同一要求
    Then 系統依冪等契約回覆原提交結果或明確衝突
    And 不建立重複 Participant、重複 Response 或重複累積分數

  Scenario: 老師公布正確答案後學員可接收正解
    Given 目前題目具有標準答案
    And 老師已明確公布該題正確答案
    And 答案分布及個人／團隊排行榜尚未公布
    When 學員檢視已公布結果
    Then 系統顯示該題已公布的正確答案
    And 不因公布正確答案而一併公開未公布的答案分布或排行榜

  Scenario: 接收統計不等於接收正確答案
    Given 老師已公布目前題目的答案分布但尚未公布正確答案
    When 學員檢視已公布結果
    Then 系統僅顯示授權公布的答案分布
    And 不顯示正確答案、未作答人數、正確率或文字回饋

  Scenario: 活動模式鎖定後以伺服器設定判定學員互動與結果
    Given TEAM 分組已確認，或首道計分題開放後活動模式已鎖定
```

## 6. 資料、欄位與邊界規則

- **Participant：** 每位活動學員以活動範圍內唯一識別值表示；不建立 M02 正式帳號。加入後由系統核發不可猜測的匿名持久憑證；有效期限、撤銷及重試限制沿用平台安全政策。同一瀏覽器及持有有效憑證的多個裝置均可恢復同一 Participant。識別值及重連憑證不得由用戶端任意指定或冒用。
- **加入資訊：** Game PIN、QR Code 與活動連結均是加入途徑，不等同 Participant 身分憑證。格式、有效期限、輪替及撤銷依 M06／平台安全政策；活動已結束或加入資訊無效時不得新增參與者。
- **暱稱與匿名：** 暱稱及匿名顯示依 M06 已核定規則。暱稱不得作為唯一鍵；匿名不得阻止系統去重、恢復原身分或限制未授權資料存取。M08 不另創不同於 M06 的暱稱欄位政策。
- **Response：** 每筆提交須關聯活動、題目快照及 Participant，並保留足以供 M09／M11 處理的題型相容答案。選擇題、投票及文字回饋在題目開放期間可更新，採最後一次成功提交為有效內容；同一提交識別的重試須冪等。欄位型別、時間戳、修改歷程及保存期間依平台／M09 資料契約。
- **題型驗證：** 單選答案須對應題目快照中的有效選項；多選答案須至少包含一個有效且不重複的選項，空集合或重複選項時拒絕整筆提交；投票只接受該投票題所定選項；文字題接受符合平台共通輸入政策的文字內容。答案修改依已確認的最後一次成功提交規則；文字長度及其他輸入安全限制沿用平台政策。
- **題目資格：** 回應須符合活動與題目狀態及 M11 資格快照。在線、已加入、已作答與具備題目計分資格不得混用。新加入者不影響已開放題目的資格快照或已結算結果。
- **計分：** 投票與自由文字預設不計分（BR-017）。M08 只提供有效提交，不判定正確答案、不計算個人或團隊分數、不決定平均方式或並列名次。
- **結果：** 學員只能取得老師已公布且符合伺服器目前鎖定的 `grouping_mode`、`leaderboard_mode` 及本人授權範圍的結果。統計、正確答案及排行榜公布狀態分離；M09-13 的未作答人數、答案分布及正確率供老師／授權報表使用；M07 控制的學員端公布統計是獨立受限資料視圖，只包含答案分布。
- **重連與去重：** 加入後由系統核發不可猜測的匿名持久 Participant 憑證；持有效憑證的多裝置可恢復原 Participant，MVP 不設活動人數上限。憑證期限、撤銷及重試限制依平台安全政策。提交重送不得產生重複 Response 或重複得分（BR-020）。
- **在線狀態：** 在線判定依平台驗證並接收的有效心跳，採最近 60 秒門檻；用戶端不得自行聲稱在線。在線人數、已加入總人數及目前題目已作答人數須分開統計；M08 不以心跳推定題目作答資格。
- **保存與資料完整性：** Participant、Response、暱稱與文字回饋的保存、刪除／匿名化依平台資料保存與隱私政策，不在 M08 自行設定保存期限或額外收集個資。

## 7. 非功能性需求

- **身分與授權安全：** 每次加入、提交、重連及結果查詢均由後端驗證活動憑證、Participant 身分、活動狀態、題目狀態及必要的題目資格。學員憑證不得取得老師控制權；權限或狀態無法驗證時拒絕，不得 fail-open。
- **資料完整性與冪等：** 提交資料須與正確活動、題目及 Participant 關聯；更新答案／文字回饋時以最後一次成功提交為有效內容。同一提交請求的網路重試、重連及並行請求不得重複建立參與者、重複寫入有效答案或重複計分。停止作答與提交依伺服器原子順序裁決。
- **結果保密：** 僅提供老師已公布且模式相容的結果；不得經未授權查詢取得未公布答案、個人／團隊分數、文字回饋或其他參與者識別資料。個人結果及隊伍結果均依最小必要原則提供。
- **即時狀態與恢復：** 學員端活動、題目及公布狀態依平台即時傳輸契約同步；斷線後使用可驗證身分恢復，不將未確認提交呈現為成功。即時更新延遲及重連服務等級沿用平台共通 NFR，不另訂數值。
- **錯誤處理：** 必要依賴無法驗證或保存時，不得回報成功或回傳未確認結果；錯誤訊息不得洩露加入憑證、Participant 識別憑證或其他學員資料。

2. **文字輸入限制：已決議沿用平台共通輸入政策。** 文字回饋的最大長度、Unicode 正規化、安全過濾規則及拒絕回應由平台共通契約定義，M08 不另訂模組專屬限制。
3. **結果格式與更新：已決議契約邊界，實作細節待同步。** M08-07／10／12 結果呈現欄位、即時更新方式及 M09 結算完成語意依 M07／M09 契約；未公布資料一律不得回傳。
4. **即時服務門檻：** 心跳頻率、事件傳遞延遲、斷線偵測及恢復服務等級依平台即時契約明定；在線判定固定採有效心跳 60 秒門檻。

## 10. 跨模組契約事項

- **M01 帳號與登入：** 學員不使用正式帳號角色；M08 參與憑證與正式帳號認證隔離。學員參與憑證不得授予 M07 控制能力。
- **M04 角色與功能權限：** 學員不是正式角色；Participant 權限依活動加入憑證、活動狀態、題目狀態與資料範圍授予。前端隱藏不能取代後端驗證。
- **M06 教學活動管理：** 提供活動擁有者、允許加入狀態、PIN／QR／連結有效性、暱稱／匿名設定、`grouping_mode`、`leaderboard_mode` 及活動結束狀態。活動結束後拒絕新加入及新互動，既有結果保存依 M06／平台資料保存政策。
- **M07 老師即時控制台：** 提供目前題目、作答開放／停止及統計／正確答案／排行榜各自的公布狀態。開放才可提交；停止與提交競態以伺服器原子順序裁決。學員端統計僅展示核准答案分布，不含未作答人數、正確率或文字回饋。
- **M09 即時統計與結果分析：** 接收 M08 已接受的 Response，計算答案分布、正確率、個人分數及個人排行榜；M08 不複製計算邏輯。M09-13 的未作答人數、答案分布及正確率是教師／授權分析資料；學員端公布統計依 M07 為獨立受限視圖，只含答案分布。團隊分數／並列名次依 M11（BR-018／BR-019）；M08 僅呈現已公布、對本人適用的結果。
- **M11 可選分組與團隊競賽：** 提供 TEAM 隊伍及成員歸屬、分組鎖定、遲到者安排、計分題資格快照、團隊分數與團隊排行榜。M08 只呈現本人所屬隊伍及已公布團隊結果；遲到者不得改寫既有快照或已結算分數。
- **平台共通契約：** 定義加入／重連憑證、心跳、即時同步、錯誤格式、冪等識別、併發順序、效能與恢復門檻。無法完成必要驗證或保存時不得 fail-open 或回報操作成功。
