# M10 系統設定與營運監控—使用者需求與驗收規格

> **來源：**《即時互動教學系統 — 系統功能規劃書 V1.2》M10（系統設定與活動監控）、M01 登入安全與 Session、M04 權限管理、M06 活動管理。
> **模組優先級：** P1。
> **規格狀態：** 草案；參數上下限、監控刷新門檻及共通 NFR 依平台政策補充。

## 1. 需求概覽

- **功能目標：** 提供系統管理者維護核准的全域系統參數，並掌握進行中活動及其彙總連線狀態，以支援平台營運。
- **範圍：** M10-01 基本參數設定、M10-02 活動監控；M10 為 P1，不作為 P0 MVP 上線門檻。
- **主要使用者：** 系統管理者；活動監控限具相應權限者。
- **設定範圍：** 活動預設值及 Session 逾時。變更只套用於新建立的活動或 Session，不回溯修改既有項目。
- **權限原則：** 所有查詢與設定變更均由後端驗證角色功能權限及資料範圍；前端隱藏不得取代後端授權。

## 2. 功能範圍

| 功能 ID | 功能名稱 | 優先級 | 功能說明 | 範圍界線 |
|---|---|---:|---|---|
| M10-01 | 基本參數設定 | P1 | 維護活動預設值及 Session 逾時兩類系統參數。 | 變更只套用於新建活動／Session；可調範圍及參數值由平台政策核定。 |
| M10-02 | 活動監控 | P1 | 由系統管理者查詢進行中活動及彙總連線狀態。 | 僅提供活動與連線摘要，以查詢為主、不含告警；過期或不可得狀態標示「未知」。 |

## 3. 使用者故事

> **身為**具備 M10 權限的系統管理者，
> **我希望**維護核准的系統參數並查看進行中活動的營運狀態，
> **以便於**維持平台設定一致並及早發現服務或連線問題。

## 4. 權責與資料規則

### 4.1 系統參數變更

1. M10-01 僅納入活動預設值及 Session 逾時；代碼、型別、允許範圍及核准值由平台政策定義。
2. 系統參數變更須受 M04 權限檢查，並依核准權限矩陣限制可修改的管理者角色。
3. 設定變更只影響變更後新建立的活動或 Session，不回溯修改已建立的活動設定或既有 Session 狀態。
4. 批次更新採全有全無；版本不符時拒絕並要求重新讀取。版本欄位、衝突回應格式及參數相依驗證等實作細節依平台 API／資料一致性契約落實，不得改變此衝突處理行為。
5. Session 逾時由 M01 定義登入 Session 語意及安全政策；M10 可調值範圍依平台政策核定。

### 4.2 活動監控

1. 活動監控僅限具權限的系統管理者查詢，提供活動識別／狀態及彙總連線摘要；不提供個別參與者連線明細。
2. 監控以查詢為主，不包含主動告警；狀態過期或無法取得時標示「未知」，有資料時顯示最後更新時間。
3. 連線狀態定義、刷新週期及新鮮度門檻由 M08／平台共通 NFR 契約核定。
4. 活動操作權仍由 M07 主持老師掌握，M10 監控不提供活動控制功能。
5. 監控資料不呈現學員個別身分或作答內容，只提供約定的活動與彙總連線摘要。

## 5. 驗收條件

```gherkin
Feature: M10 系統設定與營運監控

  Background:
    Given 所有 M10 請求均由後端驗證登入狀態、功能權限及目標資料範圍
    And 活動連線狀態定義與刷新門檻依平台契約

  Scenario: 管理者查詢活動預設值與 Session 逾時
    Given 系統管理者已登入且具備系統設定查詢權限
    When 管理者查詢 M10-01 設定
    Then 系統提供活動預設值及 Session 逾時的核准設定資料
    And 不回傳認證秘密

  Scenario: 更新參數僅套用至新建立的活動或 Session
    Given 系統管理者具備相應系統設定權限
    And 該參數及其可調整範圍已由平台政策核定
    And 已存在使用舊設定的活動或 Session
    When 管理者提交符合核定政策的新參數值
    Then 系統將更新值套用於之後新建立的活動或 Session
    And 既有活動設定與既有 Session 狀態不被回溯修改

  Scenario: 拒絕無權限的系統設定操作
    Given 使用者未具相應系統設定權限或帳號已停用
    When 使用者直接呼叫參數查詢或更新介面
    Then 後端拒絕請求
    And 不因前端隱藏功能而省略後端授權檢查

  Scenario: 系統管理者查詢活動與彙總連線摘要
    Given 系統管理者具備 M10 活動監控讀取權限
    And 系統中有進行中的活動
    When 管理者查詢活動監控
    Then 系統提供活動識別、活動狀態及彙總連線狀態
    And 不提供個別參與者連線明細或個別作答內容
    And 查詢不觸發告警或改變活動狀態

  Scenario: 連線狀態過期或無法取得
    Given 活動連線狀態已過期或來源暫時無法取得
    When 管理者查詢活動監控
    Then 系統將該連線狀態標示為「未知」
    And 若可得，顯示最後更新時間
    And 不得把過期狀態呈現為即時正常

  Scenario: 非管理者不得查詢全平台活動監控
    Given 使用者不是具 M10 活動監控權限的系統管理者
    When 使用者查詢全平台活動監控
    Then 後端拒絕請求
    And 不回傳活動或連線摘要

  Scenario: 營運監控服務暫時不可用
    Given 活動監控所需服務無法完成請求
    When 使用者查詢活動監控或提交設定變更
    Then 系統明確回報未完成或可重試狀態
    And 不回傳部分結果為完整資料、不確認未完成的設定變更
    And 不洩露內部憑證或敏感資料
```

## 6. 資料、欄位與邊界規則

- **系統參數：** 範圍為活動預設值及 Session 逾時；具體值、型別及允許範圍由平台政策核定，僅作用於新建活動／Session。
- **Session 逾時：** M01 定義逾時語意與安全政策；M10 僅提供受權限保護的設定入口。
- **活動監控：** 僅提供活動及彙總連線摘要；過期或不可得時標示「未知」，可得時附最後更新時間；不提供個人作答或連線明細。
- **資料完整性：** M10 不改寫活動、Session、結果或歷史快照；設定變更不回溯影響既有項目。
- **待落實契約：** 平台 NFR 須明定活動連線狀態、刷新週期、新鮮度門檻及服務目標；依 M10-2 已確認，資料過期或不可得時顯示「未知」。平台 API／資料一致性契約須補明 M10-3 的版本欄位、衝突回應及參數相依驗證等細節，批次全有全無、版本不符拒絕並要求重新讀取的規則已確認。活動預設值及 Session 逾時的核准值、型別與範圍由平台政策另訂（M10-1 已確認責任歸屬，具體政策值仍由平台核定）。

## 7. 非功能性需求

- **安全授權：** 每個 M10 查詢與寫入請求均須由後端驗證帳號狀態與功能權限；驗證依賴不可用時採拒絕存取，不得 fail-open。
- **設定完整性：** 新設定僅供後續新建活動／Session 使用，不回溯改寫既有設定；可調值範圍與型別依平台政策驗證。
- **隱私與資料最小化：** 活動監控限活動與彙總連線摘要，不顯示個別連線明細、個人作答或認證秘密。
- **服務狀態可信度：** 活動連線資料過期或不可得時標示「未知」，可得時顯示最後更新時間。
- **效能與可用性：** 監控刷新頻率及服務目標依平台共通 NFR 確認；監控提供查詢，不含主動告警。

## 9. 跨模組契約事項

- **M01 帳號與登入管理：** 定義登入 Session 語意及安全政策；M10 不取代認證判斷。
- **M04 角色與功能對應管理：** 提供 M10 系統設定與活動監控的後端權限矩陣。
- **M06 教學活動管理：** 提供活動建立所用的預設值；M10 預設值變更僅影響新建活動，不回溯修改既有活動設定或歷史快照。
- **M07 老師即時控制台：** 活動控制由主持老師負責；M10 活動監控不提供活動控制功能。
- **M08 學員互動管理／平台連線服務：** 提供活動彙總連線狀態及其更新時間；狀態過期或不可得時由 M10 顯示「未知」。
- **平台 NFR：** 定義監控刷新門檻、狀態新鮮度及服務目標。
