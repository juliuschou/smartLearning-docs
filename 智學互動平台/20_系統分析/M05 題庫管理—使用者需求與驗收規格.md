# M05 題庫管理—使用者需求與驗收規格

> **來源：**《即時互動教學系統 — 系統功能規劃書 V1.2》M05（題庫管理）及相關角色權限矩陣、資料模型與業務規則
> **模組優先級：** P0
> **規格狀態：** M05 需求決策已依需求方回答更新；詳細字數上限及軟刪除復原／保留期限依本文待確認事項與平台共通政策處理。

## 1. 需求概覽與假設

- **功能目標：** 讓老師建立、維護、分類、搜尋及複製可重用的題庫，並以受控的題型與答案內容支援後續教學活動。
- **範圍：** 涵蓋 M05-01～M05-06：建立題庫、維護題目及答案、管理單選／多選／投票／開放式文字題型、複製題庫、分類及搜尋／檢視題庫。
- **操作者與權限：** 預設由具備 M04 所定 M05 權限的老師操作；老師只能維護自己擁有的題庫。`SYSTEM_ADMIN` 不因管理者角色自動取得老師功能；若同時具備 `TEACHER` 角色，仍須滿足 M04 權限及資源擁有者檢查。所有限制由後端執行，不能只依賴前端隱藏操作。
- **可見範圍：** 老師僅搜尋、檢視及複製自己的題庫；V1 不提供跨老師或跨組織題庫共享及瀏覽。
- **題庫與題目欄位：** 題庫名稱及題目題幹必填；主題、描述及題目選項／答案依題型規則決定是否必填。欄位須通過基本格式驗證，暫不設定字數上限。
- **題型規則：** 單選題設定一個正確答案；多選題可設定一個以上正確答案；投票不設標準答案；開放式文字不設自動判分正解。單選／多選選項數採可作答的最低合理數量，具體最小值待產品欄位契約定義。
- **複製：** 老師只可複製自己的題庫；複製名稱、主題、描述、標籤、題目、選項及答案，成為歸屬該老師的獨立副本，預設名稱須可辨識為副本。
- **分類與搜尋：** 題庫有一個主題欄位，另可設定多個由老師自行新增、僅供本人題庫使用的標籤。關鍵字搜尋名稱、主題及標籤；支援主題／標籤篩選、依名稱或更新時間排序及分頁。
- **資料與活動關聯：** 題庫由帳號擁有，題庫包含題目；M06 可選用題庫建立活動。活動應保留當時使用題目的不可變快照，來源題庫後續編輯或刪除不得改變歷史活動題目與結果。
- **刪除：** 提供題庫軟刪除；刪除後不出現在一般清單，相關資料保留以維持活動歷史。復原操作及軟刪除資料保留期限沿用平台政策，若無平台政策則仍待確認。

## 2. 功能範圍

| 功能 ID | 功能名稱 | 功能說明 | 範圍界線 |
|---|---|---|---|
| M05-01 | 建立題庫 | 建立題庫並設定名稱、主題及描述。 | 名稱必填；主題與描述選填；欄位基本格式驗證，不設定字數上限；建立時記錄擁有者。 |
| M05-02 | 維護題目 | 新增、修改及刪除題目與答案。 | 題目題幹必填，選項／答案依題型規則驗證；已被活動引用仍可維護，既有活動快照不變。 |
| M05-03 | 題型管理 | 支援單選、多選、投票及開放式文字題型。 | 單選一個正解、多選可一個以上正解、投票無標準答案、開放式文字不設自動判分正解；不設定字數上限。 |
| M05-04 | 題庫複製 | 複製自己的題庫供其他課程使用。 | 複製名稱、主題、描述、標籤、題目、選項及答案，建立獨立副本並歸屬操作者。 |
| M05-05 | 題庫分類 | 依課程主題或標籤分類。 | 每題庫一個主題，可有多個由老師自行新增且僅供本人使用的標籤。 |
| M05-06 | 題庫查詢 | 搜尋及檢視老師自己的題庫。 | 搜尋名稱／主題／標籤；支援主題／標籤篩選、名稱／更新時間排序及分頁。 |

## 3. 使用者故事

> **身為**具備 M05 功能權限的老師，
> **我希望**建立並維護自己的題庫與題目，依課程主題或標籤整理、搜尋及複製題庫，
> **以便於**在不同課程與教學活動中重複使用教材，並維持活動歷史內容的一致性。

## 5. 資料、欄位與邊界規則

- **題庫資料：** 題庫名稱必填；主題及描述選填。題目題幹必填；基本格式驗證須拒絕空白必要值。各文字欄位暫不設定字數上限；型別及儲存格式依資料契約實作。題庫名稱不假設全域唯一。
- **題目與答案：** 題型至少包含單選、多選、投票及開放式文字。單選題須指定恰好一個正解；多選題須指定一個以上正解；投票題不設標準答案；開放式文字題不設自動判分正解。單選／多選至少提供足以作答的選項，具體最小選項數由題型欄位契約固定。題庫不自行決定活動計分及文字回答評閱方式。
- **擁有權與可見範圍：** 老師僅可查詢、檢視、維護及複製自己擁有的題庫（BR-002）；不提供跨老師或跨組織瀏覽／共享。每次讀寫及複製均須執行資源擁有者檢查。
- **複製：** 複製題庫名稱、主題、描述、標籤、題目、選項及答案，建立歸屬操作者的新獨立題庫。副本名稱須可辨識為複製品；新副本的名稱衝突處理由題庫名稱欄位契約定義。修改或刪除副本不得改動來源。
- **分類與搜尋：** 每題庫設定一個主題；老師可建立多個僅供本人使用的自訂標籤。關鍵字搜尋名稱、主題及標籤，支援主題／標籤篩選、名稱或更新時間排序及分頁；所有結果仍限本人題庫。
- **刪除與使用後維護：** 題庫及題目允許來源資料編輯／刪除，即使已被活動引用；題庫刪除採軟刪除並從一般清單隱藏。既有活動快照不可變且不受影響。軟刪除資料的復原操作與保留期限依平台政策，若無既有政策則列待確認。老師帳號停用不會刪除其題庫或教學紀錄。
- **活動快照：** M06 活動可選用題庫；規劃書建議以 `SESSION_QUESTION` 保存題目快照，避免活動後修改原始題庫影響歷史結果。快照需保留供活動結果解讀所需的題目內容；具體欄位及何時建立由 M06 契約定義。
- **稽核：** 題庫／題目建立、編輯、刪除、複製及分類依 M10 全域稽核政策記錄操作者、時間、目標及結果；其他事件欄位、失敗事件範圍與保存期限沿用 M10。不得記錄認證秘密或非必要敏感資料。

## 6. 非功能性需求

- **授權安全：** 所有 M05 API 均須由後端驗證登入狀態、帳號有效狀態及 M04 對應權限：讀取／檢視使用 `M05_READ`；建立、編輯、刪除、複製及分類使用 `M05_WRITE`。另逐次檢查題庫擁有者；前端顯示控制不是安全邊界，無法完成授權驗證時不得允許操作。
- **資料完整性：** 題庫與題目關聯須一致；新增、修改、刪除及複製不得留下半完成資料。題庫擁有者關聯不可因題庫修改或複製而被意外變更。以版本檢查偵測過期編輯並拒絕覆寫較新版本。
- **歷史一致性：** 題庫來源後續修改不得回溯改變已建立活動的題目快照、作答解讀或歷史結果；快照及保留策略由 M06／平台資料政策具體化。
- **隱私：** 搜尋、檢視及複製只可處理操作者已獲授權的題庫內容；跨老師或組織共享不得由 M05 功能名稱推定為已授權。
- **可稽核性：** 題庫重要異動依 M10 政策可追查操作者、時間、目標及結果；保存期限及欄位沿用全域政策，不另行假設。
- **可用性與效能：** 題庫搜尋、讀取及儲存的回應時間、容量、分頁和併發策略沿用平台整體 NFR；本模組不設定未核定的數值門檻。

## 9. 跨模組契約事項

- **M01 帳號與登入：** 提供已登入使用者身分及帳號有效狀態；停用帳號不得繼續呼叫 M05 受保護功能。
- **M02 角色管理：** 提供有效角色狀態；`SYSTEM_ADMIN` 不自動代表老師權限，角色停用的即時撤權依 M02／M01 契約。
- **M03 老師維護：** 老師帳號停用不刪除其歷史題庫或教學紀錄；題庫保留及擁有者關聯須支援歷史追溯。
- **M04 角色與功能對應：** M05 查詢／檢視映射至 `M05_READ`；建立、維護、刪除、複製及分類映射至 `M05_WRITE`。每個後端 API 除功能權限外均須檢查題庫擁有者；本版不提供跨擁有者共享。
- **M06 教學活動管理：** 提供題庫選用及題目快照契約，明確定義活動建立／開始時快照的時點、內容與後續來源題庫變更隔離方式。M05 不得改寫既有 `SESSION_QUESTION` 快照。
- **M07／M08／M09／M11：** 題型呈現、作答、統計及計分依活動互動與分析模組契約；M05 僅保存題庫題型內容，不自行定義活動狀態、公布流程或額外計分政策。
- **M10 系統設定與稽核：** 題庫及題目異動的稽核事件欄位、成功／失敗範圍、遮罩及保存期限依 M10 全域政策。
- **平台共通契約：** 錯誤回應、搜尋／分頁、併發控制、交易原子性、效能及依賴不可用時的處理遵循平台共通規格；必要依賴無法驗證時不得 fail-open。

## 10. 來源規則與關聯

- **M05 原始功能清單：** M05-01～M05-06 題庫建立、題目及答案維護、題型、複製、分類、查詢，來源規劃書第 328–337 行。
- **模組優先級與角色矩陣：** M05 為 P0；老師建立／編輯自己的題庫及搜尋／檢視可用題庫，來源規劃書第 41–53、296–322 行。
- **資料模型：** `USER_ACCOUNT` 擁有 `QUESTION_SET`，`QUESTION_SET` 包含 `QUESTION`；活動透過 `SESSION_QUESTION` 關聯並保存題目快照，來源規劃書第 590–635 行。
- **業務規則：** BR-002（老師只可維護自己擁有的題庫及教學活動）、BR-005（前端與後端均須落實權限檢查），來源規劃書第 645–654 行。
- **帳號停用與資料保留：** 老師停用不代表刪除歷史題庫或教學紀錄，來源規劃書第 241–251 行。
- **相關模組規格：** M01 帳號與登入；M02 角色管理；M03 老師維護與管理；M04 角色與功能對應管理；M06 教學活動管理；M07 老師即時控制台；M08 學員互動管理；M09 即時統計與結果分析；M10 系統設定與稽核；M11 可選分組與團隊競賽。
