Joint recommendation

把「可用課堂」與「正式營運」拆成兩次交付

  • Release A — 帳號式課堂 MVP：Phase B 封板、學生我的課程、老師名冊、四題型課堂流程。
  • Release B — Production readiness：archive/retention、scheduler、outbox/replay/Redis、W1–W8 容量與故障恢復。
  • 保留匿名 session-code fallback；不以 mock、placeholder 或 lite realtime 冒充完整能力。

品質關卡

每個 gate 都是停止線；未通過時，先診斷與修正，不繼續擴大功能範圍。

G0 Scope

狀態、權威文件、Phase B completion matrix。

G1 Build

Prisma validate、typecheck、lint、format、build、unit。

G2 Contract

DB-backed E2E 0 skipped；401/403、CSRF、redaction。

G3 Race

撤銷、disable、submit/close、archive/delete 競態。

G4 Production

300+1、零遺失/重複/post-close accept、故障恢復。

主要風險與回滾

高風險集中於權限競態、不可逆資料生命週期及 realtime authority。共同原則：PostgreSQL 保持唯一權威、migration 只 forward-fix、Socket 失敗不得推翻已 commit mutation。

風險防線回滾／降級
Enrollment / disable TOCTOU固定 liveSession → course → account lock order，交易內重驗。停用 student cookie path；保留 nullable accountId 與匿名流程。
Realtime 遺失與亂序先 shadow outbox，再 replay；snapshot 可替換所有 client state。停 durable publisher，退回 REST snapshot + lite notification。
Retention / deletionarchive read-only → dry-run → bounded delete → early deletion。停止 worker；不可嘗試 resurrect 已刪資料。
前後端 contract drifttyped transport adapter、OpenAPI/DTO test、真實瀏覽器 acceptance。隔離 wire parsing；先回滾 UI entry，不刪 domain data。
既有 migration每次重新查 status；不可修改已套用 SQL。application revert + 新 additive migration forward-fix。

建議下一個 Iteration

兩週只追求一件事：建立可信的 Phase B release baseline，不把新 UI 或 Redis 混進來。

Iteration 1 — 必做

  1. 完成 participant-account.e2e-spec.ts 全 suite。
  2. 驗證 enrollment removal / disable 與 join/submit 的競態。
  3. 同步 student role、CourseEnrollment、Participant identity 的權威文件。
  4. 執行 targeted → full regression，記錄 DB target、test count、0 skipped。
  5. 產出 Phase B sign-off 與已知缺口。

明確不做

  1. 不新增 Redis adapter。
  2. 不啟用 archive deletion。
  3. 不以 lite Socket contract 宣稱 replay。
  4. 不先做 mock student classroom UI。
  5. 不把 local guidance、tasks 與產品 source 混成同一 commit。

完成條件：active enrollment、duplicate join、idempotent submission、removed enrollment、disabled account、匿名 fallback、privacy projection 全有 DB-backed 證據；typecheck、lint、format、build、OpenAPI、migration status 與 git diff check 均通過。
