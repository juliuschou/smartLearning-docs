# 智學互動平台 - 技術棧

> [!info] 技術棧決策
> 本檔記錄 [[智學互動平台]] 的技術選型。屬於 M2(系統分析與設計)階段的技術選型定案。

## 技術選型

| 層級 | 技術 | 版本 | 說明 |
|---|---|---|---|
| 作業系統 | **Windows 11** | - | 正式 browser/load matrix 的基準環境 |
| 前端 | **Next.js** | M2 implementation choice | React 全端框架；React Query 管 server state，Zustand 管 ephemeral UI state |
| 後端 | **Nest.js** | M2 implementation choice | REST + Nest Gateway/Socket.IO；API 與 scheduler 先同一 service/container |
| ORM | **Prisma** | M2 implementation choice | PostgreSQL transaction、row lock、advisory lock 與 typed mapping |
| 資料庫 | **PostgreSQL** | 14+ | 全部 domain/session/result authority；UUID v7、TEXT + CHECK、transaction/lock/partial index，容量仍需 [[MVP 效能目標]] 實測 |
| 即時通訊 | **Socket.IO** | Nest Gateway | `/live` namespace、room、event sequence、outbox/replay、snapshot recovery |
| Cache/coordination | **Redis** | Auxiliary only | 只作 rate limit counter 與多 instance Socket.IO adapter，不作 domain authority |
| Reverse proxy | **Nginx** | Compose service | TLS termination、REST reverse proxy、WebSocket upgrade、bounded timeout |
| Password | **Argon2id** | `m=64MiB,t=3,p=1` baseline | 參數 benchmark 與 capacity impact 於 Phase 2/9 驗證 |
| Logging | **Pino structured log** | Backend baseline | request/correlation ID、敏感欄位 redaction、不得記 token/password/open text |
| Metrics | **基礎 metrics** | M2 contract | API/DB/Socket/outbox/aggregate/retention/runtime metrics；dashboard/alert 於 M4 驗證 |
| Load test | **Artillery 或等效 Socket.IO client** | M4 | 覆蓋 W1～W8、記錄 p50/p95/p99/max、資源與 authority correctness |
| Browser | **Chrome + Edge** | latest stable on Win11 | 正式 full-path matrix；mobile 只做 responsive smoke |

## 與專案決策的對應

| 專案決策 | 技術對應 |
|---|---|
| Web(響應式) | Next.js 支援桌面/平板/手機；正式效能矩陣以 Win11 Chrome/Edge 為主 |
| 單場 300 位學員 + 1 位老師 | Socket.IO + PostgreSQL authority + bounded outbox/backpressure；必須通過 [[MVP 效能目標]] 的 workload 與 p95/p99/正確性門檻 |
| DB 帳號(獨立帳密) | Prisma 操作 PostgreSQL；密碼使用 Argon2id baseline；Web Session 為 PostgreSQL-backed opaque token |
| 重新設計 | 全新技術棧，不沿用既有 [[投票互動系統]]；部署採 Docker Compose + Nginx |

## 需求基線與 M2 邊界

> [!important] 已定的是可觀察結果
> - Course/LiveSession、Web 帳號、participant、idempotency 與競態:[[P0 核心需求基線]]
> - QuestionDefinition/SessionQuestion 與 Web/CLI validation parity:[[題目領域契約]]
> - 歸檔、匿名原始答案、90 天保留與刪除:[[結果資料治理]]
> - 單場 300 位學員 + 1 位老師的 workload 與 p95/p99/資料正確性:[[MVP 效能目標]]

> [!note] M2 已定案；仍待實測
> - Socket.IO/Nest Gateway、`/live` namespace、room、event sequence、snapshot/replay 與 bounded outbox：見 [[即時同步與結果治理設計]]。
> - Docker Compose + Nginx + Next/Nest/PostgreSQL/Redis topology、Redis boundary、capacity budget、metrics/alerts/load matrix：見 [[架構、容量與可觀測性設計]]。
> - REST/CLI/Socket envelope、Question schema、validation token、payload hash、idempotency 與 schema version：見 [[API 與共用 Schema 設計]]。
> - PostgreSQL pool/timeout、Argon2id benchmark、W1～W8、dashboard/alert thresholds 與 failure drills 仍須 M3/M4/Phase 9 證明。
> - `open_text` 的 list/cloud/toggle 僅為非阻擋 frontend 產品決策；server plain-text projection、匿名化與 retention 已固定。

M2 的具體實作選擇不得降低上游需求文件的狀態、權限、延遲、隱私與資料正確性門檻。
