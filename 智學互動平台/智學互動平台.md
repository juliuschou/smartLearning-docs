# 智學互動平台

> [!info] 專案首頁
> 本檔為「智學互動平台」專案的首頁索引,彙整目標、範圍、狀態與相關連結。

## 專案目標

建立一個教學互動系統平台,提供課堂與線上教學場景所需的即時互動功能(如投票、問答、測驗等),讓講師能在教學過程中即時收集學員回饋、掌握理解程度,並提升學習參與度。

## 專案範圍

- 即時互動功能:投票、問答、測驗等課堂互動工具。
- 講師端與學員端的互動流程。
- 互動數據的收集與呈現。
- 老師可透過官方 Skill 與 CLI,由 AI Agent 協助在自有 draft 課程中預覽、確認並建立題目;此入口不取代既有網頁建題流程。

### 已確認決策

| 項目 | 決策 | 說明 |
|---|---|---|
| 目標使用者群體 | **單一機構內部使用** | 非對外公開平台,使用範圍限於機構內講師與學員 |
| 部署型態 | **Web(響應式)** | 以 Web 為主,適用於各種 device(桌面、平板、手機) |
| 與既有投票互動系統關係 | **重新設計** | 不沿用 [[投票互動系統]] 成果,從頭設計新平台 |
| MVP 容量基準 | **單一 LiveSession 300 位學員 + 1 位老師** | 需通過集中加入、提交、廣播、重連與資料正確性門檻,詳見 [[MVP 效能目標]] |
| 身分驗證方式 | **DB 帳號(獨立帳密)** | 帳密存放於平台資料庫,不整合 SSO 或機構既有身分系統 |
| 完成期限 | **2026-09-10** | 自 2026-08-13 起約 4 週,時程緊湊,需分階段交付 |
